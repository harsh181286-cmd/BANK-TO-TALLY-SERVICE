📥 How to Import XML File into Tally Prime
Step 1: Open Tally Prime
  • Launch Tally Prime on your computer.
  • Open the company in which you want to import the bank entries.
Step 2: Open the Import Menu
  • Press Alt + O on your keyboard.
  • Select Import.
  • Then choose Transactions.
Step 3: Select File Format
  • In the File Format option, select XML.
Step 4: Select the XML File
  • Locate the XML file generated by Bank to Tally.
  • Copy the complete file path of the XML file.
  • Paste the path into the File to Import field in Tally.
  • Alternatively, click the Browse button (if available) and select the XML file.
Step 5: Backup Option
  • When prompted with "Backup Company Data Before Import?", select No (or Yes if you wish to create a backup before importing).
Recommended: It is always a good practice to take a backup of your company data before importing any XML file.
Step 6: Start the Import
  • Press Enter to begin the import process.
  • Tally will import all the transactions from the XML file.
Step 7: Import Completed
  • Once the import is successful, Tally will display a confirmation message.
  • Your bank entries have now been successfully imported into Tally.
✅ Quick Summary
  1. Open Tally Prime.
  2. Press Alt + O → Import → Transactions.
  3. Select File Format: XML.
  4. Copy and paste the XML file path into File to Import (or browse and select the file).
  5. Choose No (or Yes, if you want to take a backup) for Backup Company Data Before Import.
  6. Press Enter to start the import.
  7. Wait for the success message.
  8. Your XML file has been imported successfully, and all entries are available in Tally.
📋 Information Required Before Generating Your Tally XML File

To ensure a smooth and error-free XML generation, please provide the following details exactly as they appear in your Tally.

1. Company Name (Mandatory)

Please provide the exact Company Name from your Tally.

How to Find It:
  1. Open Tally Prime.
  2. Press Alt + K.
  3. Select Alter.
  4. The Company Name will be displayed.
  5. Copy the exact Company Name and paste it into the form.
Important: The Company Name must match exactly with your Tally company.
2. Bank Ledger Name (Mandatory)

Please provide the exact Bank Ledger Name for the bank statement you are uploading.

How to Find It:
  1. Open Tally Prime.
  2. Press D → A → C (Display → Account Books → Cash/Bank Books).
  3. Select the bank account for which you are uploading the statement.
  4. Press Ctrl + Enter to open the ledger.
  5. Copy the exact Bank Ledger Name and paste it into the form.

Example: ICICI Bank, HDFC Bank, SBI Current Account, etc.

3. Suspense Ledger Name (For Payment & Receipt Entries)

If you want all unidentified Payment and Receipt transactions to be posted to a Suspense Ledger, please provide the exact Suspense Ledger Name from Tally.

How to Find It:
  1. Open Tally Prime.
  2. Open the required Suspense Ledger.
  3. Copy the ledger name exactly as it appears in Tally.
  4. Paste it into the form.
4. Specific Narration-wise Ledger Mapping (Optional)

If certain narrations should always be posted to a specific ledger (for example, Salary, Rent, GST, Fuel, Interest, etc.), please provide the exact Ledger Name from Tally.

How to Find It:
  1. Open the required ledger in Tally Prime.
  2. Copy the exact Ledger Name.
  3. Paste it into the form.
⚠️ Important Note
• All Company Names and Ledger Names must be copied directly from Tally.
• Do not type the names manually.
• Even a small spelling difference, extra space, or incorrect capitalization may cause Tally to create a new ledger during import instead of using the existing one.
• Providing the exact names ensures that your XML file imports correctly without creating duplicate or unwanted ledgers.
